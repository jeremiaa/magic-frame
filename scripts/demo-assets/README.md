# Demo device pictures

Three generated pictures of ordinary household devices — a car, a robot vacuum
and a washing machine — used by `scripts/demo-ha-stub.mjs` so the Status widget
can be photographed for the wiki with something that looks like a real device.

They are **generated, not photographed**, and deliberately carry no brand: no
manufacturer, no emblem, no model name. That matters twice over — a real product
photo would be somebody's copyright, and a real badge in our documentation would
read as an endorsement we never made.

They live in the repository rather than being fetched at shooting time so the
screenshots stay reproducible: `scripts/shoot-wiki.mjs` must produce the same
picture next year as it does today.
